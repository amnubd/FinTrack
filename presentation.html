01 / Motivation & Context

The Personal Finance Dilemma

⚠️

Spreadsheet Fatigue

Manual spreadsheets lack relational integrity, have zero automated validation, require cumbersome maintenance, and break under scale.

🔒

Privacy & Cloud Lock-In

Commercial SaaS applications harvest private banking metadata, monetize personal profiles, suffer downtime, and lock data behind paywalls.

📉

Absence of Foresight

Standard tools are purely retrospective. They show historical outflows but fail to model month-end category run-rates or 3-month liquidity projections.

FinTrack Goal: Deliver an offline-first desktop platform that executes enterprise financial analytics, automated compliance guardrails, and deterministic forecasts locally.

04 / Persistence Design

Relational SQLite Schema (ACID)

TABLE users
id TEXT PRIMARY KEY
name TEXT NOT NULL
email TEXT UNIQUE NOT NULL
currency TEXT DEFAULT 'INR'
monthly_income NUMERIC CHECK (>= 0)
global_budget NUMERIC CHECK (>= 0)
savings_goal NUMERIC CHECK (>= 0)
TABLE transactions
id TEXT PRIMARY KEY
user_id TEXT REFERENCES users(id) ON DELETE CASCADE
timestamp TEXT NOT NULL (ISO-8601)
category TEXT NOT NULL
amount NUMERIC CHECK (amount > 0)
payment_mode TEXT NOT NULL
type TEXT CHECK (type IN ('INCOME','EXPENSE'))
TABLE budgets
id TEXT PRIMARY KEY
user_id TEXT REFERENCES users(id) ON DELETE CASCADE
category TEXT NOT NULL
monthly_limit NUMERIC CHECK (> 0)
month INTEGER CHECK (1..12), year INTEGER
UNIQUE (user_id, category, month, year)
TABLE goals
id TEXT PRIMARY KEY
user_id TEXT REFERENCES users(id) ON DELETE CASCADE
name TEXT NOT NULL
target_amount NUMERIC CHECK (> 0)
current_amount NUMERIC CHECK (>= 0)
target_date TEXT NOT NULL
05 / Computational Output

Analytical Formulations

1. Transaction Velocity

Measures expenditure burn frequency across moving windows (W = 7, 14, 30, 60 days):

Daily_Spend = Total_Expense / W  |  Weekly_Spend = Daily_Spend × 7
2. Category Monthly Run-Rate

Extrapolates month-end category expenditure based on days elapsed (D_elapsed of D_total):

Projected_Spend = (Current_Spend / D_elapsed) × D_total
3. Month-over-Month (MoM) Variance
MoM_Change_Pct = ((Projected_Spend - Previous_Month_Spend) / Previous_Month_Spend) × 100
06 / Intelligence Pipelines

Balance Forecasting & Health Scoring

Linear Balance Projection

Projects rest-of-month liquidity using current daily net run-rates, plus sequential 3-month forward balances:

Month_End_Bal = Current_Bal + (Daily_Net × Days_Remaining)
Forward_Bal(M+1) = Month_End_Bal + (Income_Est - Expense_Est)

Composite Financial Health (0-100)

Multi-criteria weighted index grading financial stability:

  • • 40% Weight: Category budget adherence ratio
  • • 30% Weight: Global macro budget ceiling guard
  • • 30% Weight: Savings rate benchmark (≥ 20% savings)
